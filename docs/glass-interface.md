# 玻璃界面样式

沿用首页/收藏、电影、剧集、综艺、搜索、影片详情、播放、视频源管理和既有管理/设置入口，没有增加宣传区或额外内容模块。

- 系统字体，iOS 优先使用系统字体；不再下载 Google 字体。
- 冰蓝色操作色，深浅两套背景与玻璃材质变量。错误/告警仍保留红橙色，播放已确认仍使用绿色。
- 桌面悬浮侧栏与工具栏；手机安全区内的悬浮底栏；胶囊式分类筛选。
- 大圆角海报、详情、短评及管理面板，统一表单、按钮和间距。视频本身仍保持黑色画布与原播放控制。
- 玻璃仅用于主要面板，海报卡片不逐个做背景模糊，减少移动端合成开销。
- 为不支持 backdrop-filter 的浏览器提供实色回退；系统要求减少动态效果时关闭位移动画、缩放和主题转场。
- 既有账号/设置弹层继续通过 Portal 显示，避免毛玻璃祖先影响定位。

验证覆盖既有测试与生产构建、桌面/手机深浅色截图、导航折叠、搜索、详情预测速、选集/换源、片源管理、账号菜单与登录。仓库保留 main 最新版和 original 修改前版本两个分支，提交历史不做压缩改写。
