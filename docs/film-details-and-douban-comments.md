# 影片详情与豆瓣短评

影片卡片先进入 `/detail`，展示剧情简介、海报、豆瓣评分、导演/主演、最多六张横向剧照和热门短评。点击“立即播放”才进入原来的 `/play`；完整保留 source、id、prefer、stitle、stype、year 等查询参数，因此选集、切换片源和观看进度恢复继续由原播放页处理。历史收藏及旧 `/play` 链接仍有效。海报和剧照使用已有的受限图片代理。

详情页优先使用豆瓣资料；具有确定片源时也读取该源的简介作为回退。豆瓣失败、无剧照、无评分或找不到影片不会阻止播放。加载期间即可点击播放。

播放页也展示豆瓣热门短评，每页 20 条，按需加载最多至 offset=200。展示作者、星级、日期、有用数以及短评摘要（最多 80 个 Unicode 字符），提供豆瓣原文链接。评论内容作为 React 文本渲染，不插入 HTML。

## 数据来源与匹配

- 使用豆瓣现有公开 JSON 接口，不需要豆瓣账号、Cookie、D1 或新增密钥。
- 卡片上的豆瓣 ID 会传递到详情与播放页。无 ID 时调用 `movie.douban.com/j/subject_suggest`，仅在片名完整匹配且年份一致（已提供时）、结果唯一时自动关联；其他结果展示候选按钮供用户选择。
- 元数据、热门短评和剧照使用 `m.douban.com/rexxar/api/v2/movie/{id}` 及其 `interests`、`photos` 接口；豆瓣剧集也使用这个 movie 路径（tv 路径返回 404）。已用实际电影和剧集响应核验。
- API 保留站点原认证，只有受保护用户可请求。请求限定固定豆瓣地址，ID/分页参数验证，不跟随跳转，单请求超时 10 秒，响应上限 1 MiB。成功内容使用五分钟私有 HTTP 缓存；失败不缓存。
- 豆瓣可能限流、改接口或要求验证，此时显示重试/豆瓣链接，不将失败误报为“没有短评”，也不尝试绕过验证。

## 验证

新增单元/组件测试覆盖同名匹配、年份、恶意 ID、异常响应、Unicode 摘要、分页去重、纯文本输出、过期请求取消、失败重试、详情不自动播放及播放参数保留。另使用 Cloudflare Pages 构建产物和 Chromium 验证详情到播放、短评与图片显示、移动布局以及原有选集/换源流程。
