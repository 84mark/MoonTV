# 少儿栏目

`/kids` 提供 2–4、5–7、8–12 岁三组原创编辑片单，主题/关键词筛选及保留年龄筛选的详情返回路径。
节目元数据与介绍为人工策划，不捆绑视频、第三方文案或海报；年龄是家长选片参考，不是官方分级。
站内详情/播放仍依赖当前配置的影视片源，不能保证每个标题都有播放结果。

页面另有官方免费内容外链：央视少儿、PBS KIDS Video（可能有地区限制）、Khan Academy Kids（2–8 岁免费 App）。
这些官方资源不经过本站重新分发或嵌入，不将第三方 App 伪装成站内视频源。

研究参考：

- https://github.com/bitoceango/civideo ：Workers/R2/D1 的儿童视频管理，需家长自备视频。
- https://github.com/shiyuren1985-shawn/kid-player ：Android 作者白名单播放器，非稳定公共视频 API。
- https://github.com/learningequality/kolibri ：开源教育平台，需 Python 服务，内容须按各频道许可使用。
  上述项目不是可直接接入的中文少儿免费 VOD 全库，本次没有复制其代码或媒体。
