# 国内直播

在 `/domestic-live` 点击频道可在新标签打开外部直播入口。央视使用央视网，各地卫视优先链接可访问的电视台直播页，其余明确标为频道导航。MoonTV 页面不加载直播画面。

2026-11-19 对照 [iptv-org](https://github.com/iptv-org/iptv/blob/master/streams/cn.m3u)、[fanmingming/live](https://github.com/fanmingming/live)、[Free-TV/IPTV](https://github.com/Free-TV/IPTV/blob/master/lists/china.md) 核对频道范围，并参考 [电视眼卫视目录](https://www.tvyan.com/tv/) 查找网页入口。目录保存在 `src/app/domestic-live/channels.json`。外站播放和回看取决于目标网站及访问地区。
