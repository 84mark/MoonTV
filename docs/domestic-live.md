# 国内直播

`/domestic-live` 为独立栏目；原 `/live` 的目录、收藏和播放策略保留。

界面采用黑色播放器、右侧频道与节目单布局。保留央视官网列出的 20 个主频道条目，但它们本次未验证到兼容的官方直连流，因此只展示节目单并明确标为暂不可用，不导入第三方转播替代，也不嵌入无法正常跨站工作的官方播放器。

本次开启 5 个官方 HTTPS 频道：CGTN 英语、CCTV+ 直播一／二、CGTN Global Biz、China Travel。地址与浏览器解码验证时间保存在 `src/lib/domestic-live.ts`。验证来自 MoonTV 来源的真实浏览器，不代表所有地区、所有时段可用；CCTV+ 可能非全天播出，直播二实测出现过可恢复的分片 404。

所有媒体由浏览器连接已核验的 `cgtn.com` 或 `cctvplus.com` 子域名。播放器没有代理票据、Pages 媒体接口或 Worker 回退；HLS.js 加载器限制 HTTPS、域名和端口，省略 Cookie，并拒绝重定向。原生 HLS 兼容回退由浏览器处理源内子资源，不能在 JavaScript 中逐项检查原生请求。站点页面仍由原 Pages 服务托管。

节目单由浏览器直接获取央视公开 EPG API，仅请求当前频道和日期。节目单与媒体能力分开：不会因为存在历史节目就伪造可回放地址。时间轴只使用视频实际 `seekable` 范围；仅在流公开节目时间戳、且节目起点位于实际窗口内时启用节目回看。没有已验证的长时回放入口。画质选项来自真实 HLS 清单，播放、音量、画中画和全屏由当前浏览器能力提供。

验证包含浏览器真实 H.264/AAC 解码与持续播放、没有直播代理请求、央视真实节目单、不可用频道不加载媒体、手机无横向溢出，以及域名／协议限制、节目单解析和回看边界单元测试。
